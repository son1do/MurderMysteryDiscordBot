# ⏱️ マダミスユーティリティBot (MurderMystery Util Bot)

マーダーミステリー（マダミス）の議論フェーズや密談フェーズの進行をサポートする Discord Bot です。

---

## 🌟 主な機能

1. **スラッシュコマンドで簡単起動**
   - `/timer start 15` (15分)
   - `/timer start time:15m title:全体議論①` (タイトル付き)
   - コマンド実行者がVCに入っていれば、**Botも自動でそのVCへ参加**します。
2. **直感的なボタン操作**
   - ⏸️ **一時停止 / ▶️ 再開**: ルール確認や白熱した議論でのストップに対応
   - ➕ **+1分 / +3分 / +5分**: 議論の延長
   - ⏹️ **終了**: 早期終了や中断
3. **テキスト ＆ ボイスチャンネル連動通知**
   - **残り5分**: 「🔔 残り5分です」テキスト送信 ＋ チャイム音（ピンポーン）
   - **残り1分**: 「⚠️ 残り1分です」テキスト送信 ＋ チャイム音（ピンポーン）
   - **時間終了**: 「🚨 時間終了です」テキスト送信 ＋ 終了アラーム音（ピピピッ）＋ **「📢 全員をこのVCに集合させる」ボタン**（密談終了後にワンクリックで全員呼び戻し可能）
   - ※タイマー終了後もBotはVCに常駐します。次のフェーズのタイマーを待ち時間なしですぐ開始できます（切断したい時は `/timer disconnect`）。
4. **Discord API 制限（Rate Limit）対策**
   - 残り時間表示のEmbed更新は5秒おきに調整されており、Discord側の制限に引っかからず安定稼働します。
5. **ダイスロール機能**
   - `/dice` でサイコロを振れます。発言順決めや能力チェックなどに活用できます。
6. **PL管理 ＆ 発言順シャッフル / ルーレット**
   - `/pl add` でPLを登録し、`/pl shuffle` で発言順をランダムに並び替えます。
   - `/pl pick` でルーレット演出付きの1人ランダム選出ができます。
   - `/pl from-vc` でVCにいるメンバーを一括登録する機能も搭載。
7. **匿名投票機能**
   - `/vote start` でボタン式の匿名投票を作成（選択肢を省略すると `/pl` のPLリストを自動使用）。
   - PLはボタンを押すだけで匿名投票でき、何度でも投票先を変更可能。
   - GMが「📊 結果を公開」ボタンまたは `/vote result` を押すまで内訳は非公開。公開時は棒グラフ＆最多得票👑付きで表示されます。
8. **ボイスチャンネル一括操作（密談振り分け・全員集合・一斉ミュート）**
   - `/vc split` で、メインVCのメンバーをランダムに組分けして密談VCへ一斉移動（1人余る場合は自動で最後の組に合流）。
   - `/vc gather` で、複数の密談VCに散らばったメンバーを1つのVCに一斉移動できます（デフォルトで同じカテゴリー内のVCのみ対象）。
   - `/vc mute` / `/vc unmute` で、GMのルール説明やエンディング朗読時にGM以外のVCメンバーを一斉ミュート・解除できます。
9. **読み込み完了・準備OKチェック**
   - `/ready start` で「✅ 読み込み完了！」ボタンを表示。誰が終わって誰が読み込み中かをリアルタイム表示し、全員押すと自動通知＆VCチャイムで知らせてくれます。
10. **秘密メッセージ（密書）DM送信**
    - `/secret` で指定したPLにBot経由でこっそりDMを送信。送信成否の確認や、匿名密書・チャンネル到着演出にも対応しています。
11. **最終弁論・自己紹介リレータイマー**
    - `/turn start` で `/pl` リスト（またはVCメンバー）の順に1人ずつ持ち時間を計測。チャイム音と「⏭️ 次の人へ」「➕ +30秒」ボタンでサクサク回せます。
12. **キャラクター配役・重複自動抽選**
    - `/char start` でキャラ一覧ボタンを表示し、PLが希望を選択。被ったキャラだけ自動でランダム抽選し、落選者や「🎲 おまかせ」希望者を空き枠へ自動割り当てします。
13. **キャラ名ニックネーム一括変更＆自動復元**
    - `/nick from-char`（または `/char` 確定メッセージのボタン）で、全員のサーバーニックネームを `探偵（田中）` のように一括変更。終了後は `/nick reset` で元の名前に一発復元します。
14. **シナリオ概要カード投稿（BOOTH検索＆URL対応）**
    - `/scenario search` でBOOTHのマダミス作品を検索し、候補から選んでサムネ・作者・概要付きの綺麗なカードをチャットへ投稿。
    - `/scenario url` でBOOTH・マダミス.jp・ウズ等のURLから概要カードを自動生成できます。

## 🚀 セットアップ手順

### 1. Discord Developer Portal での準備

1. [Discord Developer Portal](https://discord.com/developers/applications) にアクセスしてログインします。
2. 右上の **「New Application」** をクリックし、名前（例: `MurderMysteryTimer`）を入力して作成します。
3. 左メニューの **「Bot」** を選択:
   - **「Reset Token」** をクリックして **Bot Token** をコピーします（後で使います）。
4. 左メニューの **「OAuth2」** -> **「URL Generator」** を選択:
   - **SCOPES**:
     - `bot`
     - `applications.commands`
   - **BOT PERMISSIONS**:
     - `Send Messages` (メッセージを送信)
     - `Embed Links` (埋め込みリンク)
     - `Attach Files` (ファイルを添付)
     - `Connect` (ボイスチャンネルに接続)
     - `Speak` (ボイスチャンネルで発言)
     - `Move Members` (メンバーを移動 — `/vc split` / `/vc gather` で使用)
     - `Mute Members` (メンバーをミュート — `/vc mute` / `/vc unmute` で使用)
     - `Manage Nicknames` (ニックネームの管理 — `/nick` で使用)
5. ページ最下部に生成された招待URLをコピーし、ブラウザで開いて**タイマーを使いたいDiscordサーバーに招待**します。

---

### 2. 環境変数の設定

1. フォルダ内の `.env.example` をコピーして、ファイル名を `.env` に変更します。
2. `.env` をメモ帳やテキストエディタで開き、取得したトークンを入力します:

```env
DISCORD_TOKEN=ここにコピーしたBotトークンを貼り付け
GUILD_ID=テストするサーバーのサーバーID（開発時に即時コマンド反映させたい場合）
```

> **ヒント (GUILD_ID)**:
> Discordで「開発者モード」をONにして、サーバー名を右クリック ->「サーバーIDをコピー」で取得できます。
> GUILD_ID を指定すると、スラッシュコマンドが即座にそのサーバーに反映されます（空欄の場合は全サーバー共通反映となり、反映に最大数分〜1時間ほどかかることがあります）。

---

### 3. パッケージのインストール

コマンドプロンプトやPowerShellでこのフォルダを開き、以下を実行します:

```bash
npm install
```

---

### 4. Botの起動

```bash
npm start
```

コンソールに `Logged in as MadamisuTimer#0000!` と表示されれば準備完了です！

## 🎮 使い方

### タイマー

1. Discordで、タイマーを鳴らしたいボイスチャンネル（VC）に自分が参加します。
2. 任意のテキストチャンネルでスラッシュコマンドを入力します:
   ```text
   /timer start time:15m title:全体議論①
   ```
3. BotがVCに参加し、タイマーメッセージ（Embed）が表示されてカウントダウンが始まります。
4. メッセージ下のボタンでいつでも一時停止、再開、時間の追加が可能です！

## 📋 コマンド一覧

### `/timer` — タイマー操作

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/timer start` | `time`（必須）, `title`（任意） | タイマーを開始します。`time` は `15`（15分）, `10m`, `90s`, `1h30m` などの形式 |
| `/timer stop` | — | 実行中のタイマーを停止します |
| `/timer connect` | — | あなたが入っているVCにBotを参加させます |
| `/timer disconnect` | — | BotをVCから退出させます |
| `/timer test` | `type`（任意） | VCでチャイム音のテスト再生をします |

### `/dice` — ダイスロール

| オプション | 必須 | 説明 |
|---|---|---|
| `roll` | 任意 | ダイスの形式。省略時は `1d100` |
| `comment` | 任意 | ダイスを振る理由・項目名（例: `調査`, `発言順決め`） |
| `panel` | 任意 | `True` にすると自分は振らず、**みんな用のダイスボタンパネル**だけを表示（`roll` 省略時は `1d100` / `1d6` / `2d6` / `1d20` の4ボタン） |

> 通常の `/dice` の結果メッセージ下にも、同じ条件で誰でも振れる **`🎲 <ダイス> を振る`** ボタンが自動で付きます。

**`roll` の指定例:**

| 入力 | 動作 |
|---|---|
| _(省略)_ | `1d100`（1〜100の整数をランダムに1つ） |
| `1d6` | 6面ダイスを1つ |
| `2d6` | 6面ダイスを2つ振って合計 |
| `d20` | `1d20` と同じ |
| `100` | `1d100` と同じ（面数だけの指定） |

> 個数は1〜50個、面数は1〜10,000面まで対応しています。

---

### `/pl` — PL管理・発言順シャッフル / ルーレット

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/pl add` | `name`（必須） | PLをリストに追加します |
| `/pl remove` | `name`（必須） | PLをリストから削除します |
| `/pl list` | — | 現在のPLリストを確認します（自分だけに表示） |
| `/pl clear` | — | PLリストをリセットします |
| `/pl from-vc` | — | 自分がいるVCの全メンバー（Bot除く）を一括登録します |
| `/pl shuffle` | — | PLをランダムに並び替えて発言順を表示します |
| `/pl pick` | — | ルーレット演出でランダムに1人を選出します |

**使用例（マダミスでの流れ）:**

```text
# セッション開始前にPLを登録
/pl from-vc                 ← VCメンバーをまとめて登録（おすすめ）
# または手動で1人ずつ:
/pl add name:田中
/pl add name:佐藤
/pl add name:鈴木

# 議論フェーズの発言順決め
/pl shuffle                 ← 🥇🥈🥉付きでシャッフル結果を表示

# 1人をランダムに選ぶとき（情報提供者・役割割当など）
/pl pick                    ← ルーレット演出で選出
```

### `/vote` — 匿名投票

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/vote start` | `title`（任意）, `options`（任意） | ボタン式の匿名投票を開始します。`options` はカンマ区切り（最大20個）。省略時は `/pl` のPLリストを使用 |
| `/vote status` | — | 現在の集計と「誰が誰に投票したか」の内訳をGMだけに表示します（作成者のみ・投票は継続） |
| `/vote result` | — | 投票を締め切り、棒グラフ＆最多得票👑付きで結果を公開します（作成者のみ） |
| `/vote cancel` | — | 投票を結果非公開のまま中止します（作成者のみ） |

**使用例（投票フェーズの流れ）:**

```text
# パターン1: 選択肢を指定して開始
/vote start title:犯人は誰？ options:田中,佐藤,鈴木,高橋

# パターン2: すでに /pl で登録済みなら引数なしでOK！
/vote start

# PLはメッセージ下のボタンを押すだけで匿名投票（別ボタンで変更も可能）
# 全員投票したらGMがメッセージ下の「📊 結果を公開 (GM)」ボタン（または /vote result）を押して発表！
```

### `/vc` — ボイスチャンネル操作

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/vc split` | `size`（任意）, `source`（任意）, `include_self`（任意）, `same_category`（任意） | VCメンバーをランダムに組分けして密談VCへ一斉振り分けします（デフォルト: 2人ペア、1人余る場合は最後の組に合流） |
| `/vc gather` | `target`（任意）, `same_category`（任意）, `include_bots`（任意） | 密談VCなどに散らばったメンバーを1つのVCに一斉集合させます |
| `/vc mute` | `target`（任意）, `include_self`（任意）, `include_bots`（任意） | VCにいるメンバー（デフォルトでは実行者とBotを除く）を一斉サーバーミュートします |
| `/vc unmute` | `target`（任意）, `include_bots`（任意） | VCにいるメンバーのサーバーミュートを一斉解除します |

**主なオプション:**
- `size` (`/vc split`): 1グループあたりの人数（デフォルト `2`）。5人を2人組に分ける場合などは自動で `2人 + 3人` に調整されます。移動結果メッセージ下には元のVCへ呼び戻す集合ボタンも付きます。
- `target` / `source`: 対象のVC（省略時はコマンドを実行したあなたが現在いるVC）
- `same_category` (`/vc split` / `/vc gather`): デフォルト `True`。**同じカテゴリー内のVCのみ**を対象にします（別部屋の人を誤って移動させない安全設計）。
- `include_self` (`/vc split` / `/vc mute`): デフォルト `False`。実行者（GM）自身は対象外（GMレス進行時は `True`）。
- `include_bots`: デフォルト `False`。Botは対象外（チャイム再生が止まらないように保護）。

> **必要な権限:** `/vc split` / `/vc gather` には `Move Members`（メンバーを移動）、`/vc mute` / `/vc unmute` には `Mute Members`（メンバーをミュート）権限が実行者およびBotの両方に必要です。

### `/ready` — 読み込み完了・準備OKチェック

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/ready start` | `title`（任意）, `target_count`（任意）, `include_self`（任意） | 「✅ 読み込み完了！」ボタンを表示し、完了済み／読み込み中のメンバーをリアルタイム表示します |
| `/ready cancel` | — | 進行中のチェックを中止します（作成者のみ） |

**特徴:**
- `target_count` を省略すると、**同じVCにいるメンバー（デフォルトでGMとBotを除く）** を自動で対象にします（GMレス進行の場合は `include_self:True`）。
- 全員がボタンを押した瞬間に完了通知を送信し、BotがVCに接続中ならチャイム音（`notice.wav`）も鳴ります。
- ボタンはトグル式なので、誤タップしてももう一度押せば取り消せます。

---

### `/secret` — 秘密メッセージ（密書）DM送信

| オプション | 必須 | 説明 |
|---|---|---|
| `to` | 必須 | 送り先のメンバー |
| `message` | 必須 | 秘密メッセージの本文 |
| `title` | 任意 | タイトル（例: `追加ハンドアウト`, `密書`） |
| `anonymous` | 任意 | `True` にすると差出人を「🕵️ 匿名」にして送信（デフォルト: `False`） |
| `announce` | 任意 | `True` にするとチャンネルに「✉️ 〇〇に秘密のメッセージが届きました…」と演出表示（デフォルト: `False`） |

> 送信の成功／失敗（相手がDM拒否設定の場合など）は送信者本人にだけ通知されます。

---

### `/turn` — 最終弁論・自己紹介リレータイマー

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/turn start` | `time`（必須）, `title`（任意）, `shuffle`（任意）, `members`（任意） | 1人ずつ順番に持ち時間を計測するリレータイマーを開始します |
| `/turn stop` | — | 実行中のリレータイマーを中断します |

**特徴:**
- `members` を省略すると `/pl` リスト（未登録の場合は同じVCにいるメンバー）の順番で自動開始します。
- `shuffle:True` を指定すると発言順をランダムにシャッフルして開始します。
- 時間切れになるとチャイムが鳴って待機状態になり、**「⏭️ 次の人へ」** ボタンで次の発言者へスムーズにバトンタッチできます（**「➕ +30秒」** 延長・一時停止にも対応）。

---

### `/char` — キャラクター配役・抽選

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/char start` | `characters`（必須）, `title`（任意）, `secret`（任意） | キャラクター希望選択パネルを作成（カンマ区切りで2〜20キャラ） |
| `/char resolve` | — | 希望を締め切り、配役確定＆重複自動抽選を実行します（作成者のみ） |
| `/char cancel` | — | 進行中の配役決めを中止します（作成者のみ） |

**特徴:**
- **段階的抽選（ラウンド制）**: 希望が1人だけのキャラはその場で確定、2人以上被ったキャラは抽選で1人確定し、外れた人は残りの空きキャラから次ラウンドで希望を選び直せます。
- 確定済みキャラのボタンは自動で無効化され、確定済みのPLは誤操作できないよう保護されます。
- 空きキャラが残り1つになった場合や **「🎲 おまかせ」** を選んだ人は、自動で最終枠へ割り当てられます。
- `secret:True` を指定すると、抽選まで誰がどのキャラを希望しているか非公開にすることもできます。

---

### `/nick` — キャラ名ニックネーム一括変更・復元

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/nick from-char` | `format`（任意） | 直近の `/char` 配役確定結果をもとに、全員のニックネームを一括変更します |
| `/nick set` | `user`（必須）, `character`（必須）, `format`（任意） | 指定メンバーのニックネームをキャラ名に変更します |
| `/nick reset` | — | このBotで変更した全員のニックネームを元の名前へ一括復元します |
| `/nick list` | — | 現在復元対象として保存されているメンバー一覧を確認します |

**`format` の選択肢:**
- `both`（デフォルト）: `キャラ名（元の名前）`（例: `探偵（田中）`）
- `char_only`: `キャラ名のみ`（例: `探偵`）

> **必要な権限:** 実行者およびBotに `Manage Nicknames`（ニックネームの管理）権限が必要です。なお、Discordの仕様上、**サーバー所有者やBotより上位ロールのメンバー**はBotから変更できないため、変更できなかった場合は手動変更用の候補名を表示します。

### `/scenario` — シナリオ概要カード投稿

| サブコマンド | オプション | 説明 |
|---|---|---|
| `/scenario search` | `title`（必須） | BOOTHからマダミス作品を検索し、GMだけに候補を表示 → 選んだ作品の概要カードをチャンネルに投稿します |
| `/scenario url` | `url`（必須）, `preview`（任意） | BOOTH・マダミス.jp・ウズ等のURLからタイトル・サムネ・あらすじを整形して投稿します（`preview:True` で自分だけに事前確認） |
